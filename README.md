# ScamShield – Phishing & Scam URL Detection System

ScamShield is a cybersecurity web application that analyzes URLs and detects suspicious or potentially phishing-related patterns.

## Features

- 🔍 URL risk analysis
- 🛡️ Phishing and scam pattern detection
- 📊 Risk score from 0–100
- 🚦 Low, Medium and High risk levels
- 🌐 Domain and DNS information
- 📜 Scan history
- 📈 Dashboard with scan statistics
- 💻 Simple web-based interface

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
